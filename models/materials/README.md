# A3 finish sources

The apartment uses locally bundled color and OpenGL normal maps from the following CC0 material scans. The authoring script reduces their dimensions, adjusts the fabric color, and embeds the results in the editable master. The web GLB uses Basis Universal KTX2 textures.

- Natural Walnut Veneer by Jenelle van Heerden. [Poly Haven](https://polyhaven.com/a/natural_walnut_veneer)
- Marble 01. [Poly Haven](https://polyhaven.com/a/marble_01)
- Wool Bouclé by Rico Cilliers and colormass. [Poly Haven](https://polyhaven.com/a/wool_boucle)

These finishes and the lighting scheme are illustrative. The photographic texture licenses and source links document material provenance. [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
