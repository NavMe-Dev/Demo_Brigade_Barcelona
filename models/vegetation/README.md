# Fern model

`fern-02.glb` contains the four variants of Poly Haven's [Fern 02](https://polyhaven.com/a/fern_02), modeled by Rico Cilliers and scanned by Rob Tuytel. It is distributed under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The source is the 1K glTF with the separately published alpha map merged into its diffuse image. The exterior generator links those variants in the Sky Deck and Eco Deck. The distant exterior retains the cheaper existing vegetation.
