## Reproduction

Use the [bundled developer brochure](../sources/brigade-barcelona-brochure.pdf) to recreate the crops. The [geographic source folder](../sources/geography/) includes HMDA’s page-22 coordinate table, the original OSM XML and the four Terrarium input tiles. The extracted sheets and geographic inputs needed by the application are also bundled. Blender 4.3, gltfpack, Python imaging/geospatial dependencies and the packed material files support offline geometry authoring from the provided inputs. Re-fetching regional satellite imagery needs access to the licensed source. [Exterior rebuild](../models/README.md) · [Apartment batch rebuild](APARTMENT_MODELS.md) · [Original A3 rebuild](apartment-authoring.md) · [Geographic credits](../dist/assets/geography/CREDITS.txt)

The runtime supports Meshopt-compressed GLBs, local Basis/KTX2 transcoding, PBR materials and the bundled HDR environment. The twelve additional apartments have a 512-pixel baked lighting atlas and A3 has a 1024-pixel atlas. The walkthrough and roof-off views share geometry. Detached component GLBs are included for independent inspection in glTF viewers and Blender.
