# Esri imagery integration

The implementation retains Three.js and the existing local metric coordinates so the architectural materials, apartment placements, selection and camera controls can share one outdoor scene. ArcGIS REST raster tiles are a supported integration surface for that renderer. An ArcGIS SceneView migration would require rebuilding the current custom materials and selection behavior, and would provide no verified textured local scene layer from the services examined. [Documented raster tile endpoint](https://developers.arcgis.com/rest/basemap-styles/service-data/) · [Local coverage](GEOGRAPHIC_COVERAGE_REPORT.md)

The operator supplied an ArcGIS browser key during this integration. Live Chrome verification received World Imagery tiles and completed the bounded World Elevation sample grid. The existing credential is used without changing the account or activating billing. An authentication failure must retain the architectural ground, connected roads and shared apartment environment. The historical Sentinel package has 10 m source pixels and is unsuitable for immediate architectural ground. The new hybrid terrain uses authored near-ground materials and a geographic transition outside the site.

## Configuration and entitlement

The local server reads `ARCGIS_IMAGERY_ENABLED` and `ARCGIS_API_KEY` from the process environment or `.env.local`, and exposes the browser configuration through `data/arcgis-runtime.json`. The enabled flag is effective only with a nonempty key. A static deployment needs an equivalent runtime configuration. Browser keys are visible to their authorized client, so restrict the key to the necessary basemap privilege and application origins in the ArcGIS credential settings. Use the account holder’s approved entitlement. Preserve `.env.local` outside version control. [Server](../scripts/serve.py) · [Example](../.env.example) · [Esri authentication and referrers](https://developers.arcgis.com/documentation/security-and-authentication/faq/)

The supported imagery URL is `https://ibasemaps-api.arcgis.com/arcgis/rest/services/World_Imagery/MapServer`. The imagery client uses the supported `token` query parameter and `cache: 'no-store'`. Its imagery endpoint rejected the Authorization header during browser CORS preflight. The credential is omitted from console output, reports and stored request logs. It validates Web Mercator metadata, citation resolution and per-area tile availability before fetching the tile hierarchy. At Plot 20, the public no-key probe found source imagery at 0.31 m and local availability through level 19. A global cache maximum of level 23 does not establish that level at the property. [Streaming implementation](../dist/gis-arcgis.js) · [Coverage probe](../scripts/probe_esri_coverage.py)

Current Location Platform pricing lists 2 million basemap tiles per month included and USD 0.15 per 1,000 further tiles. For example, 100,000 tile requests cost USD 15 after the free allowance is exhausted. A working-set memory limit bounds resident tiles, while total requested tiles depend on navigation and revisits. Account usage and limits belong to the account holder. Billing was not activated by this change. [Current pricing](https://developers.arcgis.com/pricing/)

## Imagery lifecycle and attribution

The client refines imagery according to the camera and projected pixel size. Available parents stay visible while finer tiles load. Finer tiles fade over 180 ms, and sampling uses mipmaps and anisotropic filtering. Its default bounded working set is 32 image tiles and two concurrent requests on mobile, and 64 tiles and four requests on desktop. A camera change aborts obsolete requests. Suspension cancels pending loads. Teardown releases tile buffers, image resources and GPU objects. The proprietary tile bytes remain in transient memory. [Client](../dist/gis-arcgis.js)

When Esri imagery is displayed, show a linked Powered by Esri credit and the copyright text returned by the live service, including the local imagery contributor. The public citation currently identifies Vantor and Earthstar Geographics. Each independently sourced terrain, footprint, road and vegetation asset retains its own attribution. Public reachability of an endpoint does not establish commercial redistribution permission. [Esri attribution](https://developers.arcgis.com/openlayers/maps/raster-tile-basemaps/display-a-map/) · [Esri terms](https://www.esri.com/en-us/legal/overview) · [Local geographic credits](../dist/assets/geography/CREDITS.txt)

The full-width source strip has been replaced by a compact corner control across both application routes. The linked Esri credit remains visible when imagery or elevation uses Esri, while **Map credits** opens the full live source notices in a dialog. **Retry map** remains available beside the compact control during failures. The control is independent of the apartment's Hide interface setting.

## Elevation and 3D coverage

World Elevation metadata at the parcel identifies 24.74 m Airbus WorldDEM4Ortho in EGM2008 and 30.92 m SRTM in EGM96. The live `WorldElevation/Terrain/ImageServer/getSamples` operation accepted the configured key and explicit 24 m pixel-size request. The loader samples a 65 × 65 grid across ±2,048 m, with 64 m spacing, in 45 requests of at most 96 locations and four requests in parallel. Browser acceptance returned all 4,225 samples in 4.905 seconds from one Airbus WorldDEM4Ortho source. The origin value was 595.055 m in EGM2008. [Supported sample operation](https://developers.arcgis.com/rest/services-reference/enterprise/get-samples/) · [Terrain service](https://elevation.arcgis.com/arcgis/rest/services/WorldElevation/Terrain/ImageServer) · [Loader](../dist/gis-elevation.js)

The loader awaits the complete validated grid before terrain, roads or building bases are created. It subtracts the Esri origin value to establish relative local relief. The existing authored parcel surface and an 8 m exterior margin remain the vertical reference, with blending into Esri relief through 128 m outside the parcel. The Esri field fades into the open DEM between 1,536 and 2,048 m from the origin. Every final sample is re-evaluated on the existing 32 m triangle grid so roads and ground use one interpolation rule. This is an approximate local vertical registration across two source datums. It cannot certify orthometric or finished-floor elevation. The final 32 m mesh spacing does not increase the 64 m sample-grid detail or the native source accuracy.

A failed, incomplete, mixed-datum, insufficient-resolution or timed-out request discards the new grid and retains the open terrain. The loader has a 12-second overall limit and holds provider samples only in session memory. `Terrain3D/getSamples` was also evaluated and returned a coarse WorldDTM overview despite the requested local pixel size. That response was rejected. The selected `WorldElevation/Terrain` service returned the local source attributes and useful relief. No live terrain changes occur after meshes are built.

The current public 3D basemap indices contain geometry within 5 km, but all three inspected layers expose zero texture sets. No public photogrammetric mesh covering Plot 20 was verified. Independently licensed Overture and OSM footprints are usable for clearly identified approximations. The source report distinguishes attributed heights, floor-derived heights and estimates.
