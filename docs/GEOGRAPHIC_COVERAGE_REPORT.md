# Geographic coverage at Brigade Barcelona

Rechecked on 27 November 2026, Esri’s imagery citation for the registered Plot 20 origin identified **0.31 m WorldView‑3 imagery acquired 19 May 2026**. Three hosted building services contained untextured 3D objects within 5 km. The search did not establish a publicly accessible photogrammetric mesh for Kokapet. The application has a supported authenticated World Imagery client. The operator subsequently supplied a browser key, and live imagery and terrain requests succeeded in Chrome. The geographic data package contains independently licensed elevation, footprints and historical fallback imagery. The immediate ground in the new hybrid environment uses authored materials. ## Coordinate and elevation limits

Geographic coordinates use WGS84 longitude and latitude. The browser uses a local metric X/Z plane and Y up. True east in model axes is (−0.233699171, −0.972308952), and true north is (−0.972308952, +0.233699171). Imagery tiles use Web Mercator. The open DEM estimate at the origin is 596.286 m in EGM96. Live Esri terrain returned 595.055 m in EGM2008. The implementation subtracts the Esri origin from its local samples, then blends relative relief into the existing terrain frame. This is an approximate local registration across source datums. The project pad, entrance and tower orientation are conceptual registrations. The published parcel establishes a site boundary, while approved tower set-out and finished floor levels remain required for survey accuracy. The brochure location map supports neighborhood identification. Brigade’s September 2026 company announcement confirms the Neopolis project and 4.04-acre land acquisition but supplies no surveyed tower origin. ## Service costs

The current ArcGIS Location Platform list price includes 2 million basemap tiles per month, followed by USD 0.15 per 1,000 tiles. At 100 loaded tiles per visit, 1,000 visits generate approximately 100,000 requests and an incremental charge of USD 15 if the account’s free allocation is already exhausted. Actual requests vary with viewport, zoom, cache, camera travel and retries. Existing ArcGIS Online or enterprise agreements can have different terms. The supplied key was accepted for the selected World Elevation sample operation. Account-specific usage limits and any elevation or scene-service charges remain governed by the operator’s plan. The public basemap price does not establish a per-sample terrain charge. [ArcGIS pricing](https://developers.arcgis.com/pricing/)

## Reproduction

`python3 scripts/probe_esri_coverage.py --output /tmp/kokapet-coverage.json` repeats the public point queries, tile cache-index checks and I3S index traversal. The traversal converts geodetic node centers to ECEF and tests their bounding spheres against a 5 km radius, retaining mesh-bearing nodes wholly inside the neighborhood. This establishes local 3D geometry; a node can contain many buildings and does not identify any single tower. The script reads JSON metadata and node indices without retrieving imagery tiles, mesh buffers or textures. Service content and catalog results can change.
